## Deviations

Each is recorded in PLAN.md §7.1 (native interop / detection choices) or §7.3
(suppressions):

- **Optional features via WMI, not DISM.** `Win32_OptionalFeature` is strictly
  read-only and queryable unelevated (and thus testable on an unelevated box),
  whereas a DISM online session requires elevation and can modify the image.
- **P/Invoke via `[LibraryImport]`, not CsWin32** (power, WTS interactive user).
  No build-time generator dependency; AOT/trim-safe stubs;
  `AllowUnsafeBlocks` enabled for the Windows project only and every P/Invoke
  pins `DllImportSearchPath.System32` (CA5392).
- **Group Policy ownership via the Local GPO `Registry.pol` (a new read-only
  PReg parser), not RSOP.** The `.pol` files are world-readable — no elevation,
  deterministic, unit-testable — while RSOP needs administrator rights and is
  empty on an unmanaged machine. Per-value MDM attribution and per-user MLGPO
  are deferred to M5 (they need identifiers the M2 signature/catalogue lack); an
  unattributable value is reported NotManaged, the safe direction.
- **Mutation testing deferred.** Stryker.NET does not support
  Microsoft.Testing.Platform (stryker-net#3094) and this repo mandates MTP; the
  step is wired and pinned but reports DEFERRED until upstream support lands.
- **Protected-process (PPL) service detection** reports a conservative `false`
  and is completed in M3, where it guards apply; it is not part of scan
  compliance.
- **`S1075` suppression** on `AppInfo.HomepageUri` (the SARIF tool
  `informationUri`), an immutable product-identity constant, recorded in
  PLAN.md §7.3.
