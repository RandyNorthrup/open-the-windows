# Journal format

Every apply and revert run writes a **journal**: a tamper-evident record of
what the engine intended to change, the state it captured **before** each
change, and what actually happened. The journal is the safety core — revert
replays it, and an auditor reads it to know exactly what a run did.

## Location and permissions

- Directory: `%ProgramData%\OpenTheWindows\journal`
- File name: `<yyyyMMdd-HHmmss>-<runId>.json` (UTC start time + run GUID)
- ACL (applied when the directory is created): **Administrators** and
  **SYSTEM** full control, the creating operator full control, **Users**
  read-only. A standard user can read the history but cannot alter it.

## Lifecycle

1. The engine builds the full record with every action's **`prior`** state and
   writes it with `Begin` **before the first machine write**. If the process
   dies mid-run, the priors are already on disk for recovery.
2. After each action the record is re-flushed (`Update`) with that action's
   `appliedAt`, `verified` and `result`.
3. On success the run `result` is `Completed`; on any failure the engine rolls
   back every already-applied action in reverse and the run `result` becomes
   `RolledBack` (or `Failed` if a rollback step itself failed).

## Hash chain

- `hash` is the SHA-256 (lower-case hex) of the document **with the `hash`
  field omitted**, so a stored hash can be recomputed and compared.
- `previousHash` is the `hash` of the newest earlier journal in the directory,
  or absent for the first run. Together they chain the directory so a deleted or
  edited journal is detectable.

## Schema (version 1)

Source-generated by `JournalJsonContext`; unknown members are rejected on read.
Null union fields are omitted, so each action carries only the fields relevant
to its kind.

```json
{
  "schemaVersion": 1,
  "runId": "37e93a65-4f51-4619-afde-f66383a1bd48",
  "startedAt": "2026-08-17T20:00:00+00:00",
  "appVersion": "0.2.0",
  "os": { "build": 26100, "revision": 4351, "editionId": "Professional" },
  "profile": "balanced",
  "operator": "WIN-11-VM\\Randy",
  "targetUser": { "sid": "S-1-5-21-...", "name": "WIN-11-VM\\Randy" },
  "restorePoint": { "requested": true, "created": false, "reason": "Skipped24h", "sequenceNumber": null },
  "entries": [
    {
      "id": "privacy.advertising-id.disable",
      "risk": "Safe",
      "requires": "None",
      "actions": [
        {
          "index": 0,
          "kind": "Registry",
          "target": "HKU\\S-1-5-21-...\\Software\\Microsoft\\Windows\\CurrentVersion\\AdvertisingInfo!Enabled",
          "action": { "kind": "Registry", "hive": "User", "path": "Software\\...\\AdvertisingInfo", "name": "Enabled", "type": "Dword", "value": 0, "default": 1, "valueKind": "Preference" },
          "prior": { "exists": true, "type": "Dword", "data": 1 },
          "desired": { "type": "Dword", "data": 0 },
          "appliedAt": "2026-08-17T20:00:01+00:00",
          "verified": true,
          "result": "Applied"
        }
      ],
      "result": "Applied"
    }
  ],
  "result": "Completed",
  "requires": "None",
  "revertOf": null,
  "previousHash": "…-or-absent",
  "hash": "sha256-of-this-document-without-the-hash-field"
}
```

### Fields

| Field | Meaning |
| ------- | --------- |
| `runId` | Unique id of this run; `revert` targets it. |
| `operator` | The elevating account (`DOMAIN\user`). |
| `targetUser` | The interactive user whose `HKU\<sid>` per-user changes targeted; absent when the run made no per-user changes. |
| `restorePoint` | Truthful System Restore outcome: `Created` / `Skipped24h` / `Disabled` / `Failed` / `NotRequested`, with the sequence number when created. |
| `entries[].action` | The full catalogue action, so revert is replayable **from the journal alone** (no dependency on the catalogue at revert time). |
| `entries[].actions[].prior` | The state captured before the change; revert restores exactly this, including "the value was absent" (`{ "exists": false }`). |
| `entries[].actions[].result` | `Pending` → `Applied` / `Failed` / `RolledBack` / `Skipped` / `NotApplicable`. |
| `result` | `InProgress` while running, then `Completed` / `RolledBack` / `Failed`. |
| `requires` | Aggregate restart requirement over applied entries (`None` / `ExplorerRestart` / `SignOut` / `Reboot`). |
| `revertOf` | When set, the `runId` this run reverted. |

## Per-kind `prior` / `desired` shapes

| Kind | Fields used |
| ------ | ------------- |
| Registry | `exists`, `type`, `data` |
| Service | `exists`, `startType`, `running` |
| ScheduledTask | `exists`, `enabled` |
| OptionalFeature | `exists`, `enabled` |
| Appx | `exists`, `installedForUser`, `installedForAnyUser`, `deprovisioned` |
| DefenderPreference | `exists`, `data` |
| PowerSetting | `exists`, `ac`, `dc` |
| Command | none (`prior` is absent; revert runs the action's revert arguments) |
